# Omni-OS 1.12.0

> **ATENÇÃO — mudança incompatível: a carteira local foi removida.**
> O arquivo `trader/wallet/local_wallet.py` não existe mais. O Omni-OS não guarda, não importa, não exporta e não assina com nenhuma chave privada.
>
> **Antes de atualizar, é obrigatório mover seus fundos para a Carteira Seraph ou exportar a chave privada usando a versão 1.11.x, antes de instalar a 1.12.0.** Depois da atualização, o Omni-OS não tem mais como exibir essa chave.
>
> **Chaves importadas em versões anteriores NÃO são migradas e NÃO são apagadas.** O arquivo antigo permanece no disco, sem uso, em `%LOCALAPPDATA%\Omni-OS\config\trader\wallet\local-wallet.enc`, cifrado por DPAPI do Windows. Nenhum código da 1.12.0 lê, migra ou remove esse arquivo.
>
> Isso não significa perda de fundos: significa perda de acesso à chave pela versão 1.12.0. O arquivo continua no disco e ainda pode ser recuperado com a versão antiga. Não há migração automática de fundos nem de chave privada.

## Novidades

### Login obrigatório no Seraph

O Trader Panel só fica disponível depois da autenticação no Seraph. Não há opção de pular o login. Você pode entrar por email, SMS ou carteira (MetaMask/SIWE), pelo navegador.

### API key automática

A API key do dispositivo é criada automaticamente ao fim do login: nada para copiar ou colar. O único botão de saída, **"Desconectar este dispositivo"**, revoga a key no servidor e limpa o estado local. Se a key for revogada no console, o app recria uma nova de forma transparente na próxima chamada.

### Carteira Seraph

A Carteira Seraph é uma carteira custodial criada no login. A assinatura acontece no servidor, autorizada por um signer delegado que você concede e revoga no console. O app mostra endereço, estado do signer e saldos por rede, tudo somente leitura.

Quem entra com uma carteira externa, como MetaMask, vê as duas carteiras, mas **só a Carteira Seraph opera — deposite os fundos nela**. Retiradas são assinadas por você no console.

### Execução pelo Seraph

Toda transação é avaliada e depois executada pelo servidor usando o identificador da avaliação. Os campos da transação nunca viajam no pedido de execução.

Os limites são aplicados no servidor: **0.02 ETH por transação, 0.2 ETH e 20 transações por dia**, restrito a swaps Uniswap, approve e unwrap em **7 redes**.

### Modo paper inalterado

Após a autenticação, escaneamento, watchlist e ordens simuladas continuam funcionando sem autorizar a carteira. No navegador, o primeiro consentimento autoriza criar a API key do dispositivo; o segundo, quando solicitado para execução de transações e ainda não concedido, autoriza o signer. Escolher **"Agora não"** no segundo consentimento não cancela o login nem a criação da key: o trader continua em modo paper. Apenas o modo live fica indisponível até a autorização do signer.

## Correções

- **Migração da key manual:** uma API key do Seraph salva em versões anteriores é migrada automaticamente, uma única vez, do JSON em claro para o armazenamento cifrado do app. As demais chaves do arquivo são preservadas. Essa migração é de API key, não de chave privada de carteira.
- **Caminho do arquivo de chaves corrigido:** o cliente MCP lia `api_keys.json` a partir do diretório do código-fonte, o que não funciona em builds empacotados. Agora usa o diretório de dados do aplicativo, igual ao restante do app.

## Requisitos

- Conta no Seraph: <https://seraph.kondux.io>. Login por email, SMS ou carteira.
- Para operar em live: autorizar a Carteira Seraph no console e depositar fundos nela.

## Notas de migração

1. **Antes de instalar a 1.12.0**, use a 1.11.x para mover os fundos para a Carteira Seraph ou exportar sua chave privada. A versão nova não oferece acesso à antiga chave local.
2. Ao abrir o Trader Panel na 1.12.0, autentique-se no Seraph. A API key é criada automaticamente. O caminho alternativo para informar uma API key manual continua disponível, mas essa key não carrega o escopo de execução; o modo live é recusado com uma mensagem explícita.
3. Para operar em live, autorize o signer no console e deposite na Carteira Seraph, não na carteira externa usada para login. A autorização pode ser revogada a qualquer momento no console.
4. O arquivo legado `%LOCALAPPDATA%\Omni-OS\config\trader\wallet\local-wallet.enc` permanece intocado. Se você já atualizou sem exportar a chave, a recuperação ainda depende da versão antiga; a 1.12.0 não lê nem remove esse arquivo.
